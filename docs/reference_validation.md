# Case A 参考求解与原网络回归状态

本模块保留原代码的HLL、分裂步进、床坡源和半隐式Manning处理。它是可重复的合成回归求解器，不是民雄真实地形的可信参考；没有复杂地形静水平衡或外部观测精度认证。

## 已修正并验证

- 标准HLL只有一次总波速分母；x/y通量现在旋转一致，等状态返回物理通量，镜像状态满足法向反转关系。
- 在网格除法/内存分配之前检查整数维度、有限参数与非负目标时间。
- 逐目标时刻步进，在停雨点截步，对每步雨量精确积分；极近/极小时间也不因1e-9容差被遗漏。重复时刻去重，输出字典键为实际目标时间。
- 参数化增加`manning_n,cfl,max_dt,max_steps`用于可控回归。默认`max_dt=.5s`限制所有步长，原长步结果可能有变化，这是精度控制，不要求复现旧错误。
- PINN摩擦采用守恒形式`g*n²*h*|U|*u/h_reg^(4/3)`，湿区等价h^(-1/3)；制造恒定场测试确认量纲、方向与地形源。
- 原网络相同state_dict下前向逐值一致；归档原文件SHA-256不变；导入不执行训练或产生输出目录。
- LBFGS固定点closure重复调用Loss和所有模型梯度逐值一致。

`run_fv_A(...,return_diagnostics=False)`仍返回`{t: h_array}`；设为True返回`(snapshots, diagnostics)`。诊断包括步数、实际快照时刻、雨量、末储水、水量余差、负水深截断增加的体积、截断格次、动量裁剪格次、干格动量清零格次、方法与未外部验证标记。裁剪计数是格次而非唯一格数量。

## 实测轻量基准

命令：`.venv/bin/python -m unittest discover -s tests -p test_reference.py -v`，以及同目录`test_model.py`。

- 平地封闭均匀雨，在4/8/12格与不同最大步长上符合`h=R*min(t,T_rain)`；零雨保持全干；停雨总雨量和储水一致。
- HLL标准两状态、等状态、镜像和旋转通过。
- 斜面合成检查：坡度.01、100mm/hr、t=20s、ny=4、max_dt=.1s。nx=8/16/32相对于nx=64分块平均参考的深度RMSE约为1.1705e-4、5.9794e-5、1.8906e-5m，呈空间细化改善；4次运行水量余差绝对值约1e-18m³、无水深或动量裁剪。这只证明此小案例的自一致性，不证明绝对误差。
- 同一斜面nx=32，max_dt=.2/.1/.05s相对于.025s结果的深度RMSE约2.4109e-6/2.4382e-6/1.2886e-6m。粗级别并非严格单调，原有湿干阈值切换和分裂源项仍影响时间收敛；不能用这组数据认证全方法收敛阶。平地解析案例则保持精确雨量。
- 极端坡度仅用于触发动量裁剪计数，不属于可信物理应用范围。

## 保留的限制

地形仍仅固定斜面，边界四壁反射；只返回水深，没有FV速度参考。干深地板修改面上的状态；负水深截零可能增加体积，动量裁剪和干格清零修改动量，均保留但现在透明记录。未加入hydrostatic reconstruction，因此不能声称通过复杂床面/干湿岸线的lake-at-rest检验。运行预算超限或非有限状态会抛错，不返回伪正常参考。

下一步真实地形参考需要可信外部二维浅水求解结果或独立验证过的求解器；不能直接用此函数生成民雄全域“真值”。上述测试均为短CPU回归，没有完整PINN训练。
