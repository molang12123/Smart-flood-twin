## 端到端短跑与明确的失败结论

可查看当前实例的`outputs/final_demo/training/`、`prediction/`和`assessment.json`。这是30格、6秒物理时域、16宽2层的人工平地示例，非民雄地形；100次Adam加最多5次LBFGS内部迭代，优化预算60秒。参考是平地封闭均匀雨解析式，并非真实淹水观测。

完整流程生成了history/report/PDE/参考指标、模型包、5帧CSV、71个唯一面的交换表、逐格/全域账本、摘要/元数据、manifest和图表。终端返回training_completed/complete只表示任务执行结束，不等于converged或validated。

该短训模型**未通过示例误差/水量门槛**：独立测试雨情的深度和连续残差仍较大，初始人工水量与全域余差也明显。评估命令保存失败项并返回退出码2；不放宽阈值、不清除失败、不将短训权重加入validated_domain。所有研究推理输出明确`research_unvalidated`。

本实例最终短跑优化约2.88秒，加载约0.006秒、完整5帧推理/求积/导出及绘图约1.67秒，进程峰值RSS约281MiB。留出测试水深相对L2约41.1%，最大时刻全域水量余差约0.525m³，因此不能作为可信预测。小型合成性能不能外推全乡或GPU。机器可读结果见`verification_results.json`；原始CSV/JSON位于上述outputs目录。

示例门槛在`configs/synthetic_standards.json`，仅用于演示可解释检查，不是团队已批准的民雄业务标准。`assess`比较指定指标，不自动认证外部准确性或修改模型有效域。

## 尚不能宣称完成的部分

| 项目 | 状态/下一步条件 |
|---|---|
| 民雄真实地形与水文适用性 | 尚无团队标准DEM、地形语义/CRS/高程基准、实际域和初边界；收到后逐项检验，不能假定现有矩形全墙代表乡界 |
| 开放边界、非干初值、掩膜/内障碍 | 当前未实现；需要团队实际域和物理条件后做针对性扩展，不是仅补文件路径即可直接运行 |
| 正式单情境精度与多雨情泛化 | 需可信参考、团队误差/性能门槛、雨情范围和经确认的完整训练预算；当前短跑未达标 |
| 生产模型有效域 | 没有已通过证据，validated_domain为空；默认predict拒绝生产预测 |
| 建筑/入渗/排水 | 未建模，不能把n或DEM视为已包含地下排水等作用 |
| GPU/全乡性能 | 仅CPU合成实例实测；未验证GPU、全乡训练成本或实时延迟 |
| 精确续训 | 推理权重和配置已保存，但未实现optimizer/scheduler/RNG全状态恢复 |
| API/UE端到端 | PINN侧接口/格式/单位/数学测试完成；服务器/场景由其他成员实施，实际团队消费联调未执行 |
