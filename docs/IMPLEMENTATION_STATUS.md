# 本批实现与验证状态

## 2026-11 v12 当前发布

当前已部署 low/medium 两专家理想化模型，连续输入范围为 `0–300 mm/hr`、降雨 `1–24 h`、模拟最长 `36 h`。两个专家的个别物理门槛、连续输入域及完整 212,239 格 DEM 水量审核均通过；30–50 mm/hr 使用线性凸混合。原始专家空间水深差异最坏为 20.4941%，按用户确认的理想化展示目标采用 25% 重叠上限，平均蓄水差仍小于 2%。模型不是实测淹水精度认证。

批准包位于 `models/minxiong/experts/`，全套自动测试为 **224/224 通过**。完整证据与限制见 `MINXIONG_0_300_TRAINING_STATUS.md`。以下 v9/v10 内容保留为 0–800 失败实验与软件演进历史，不代表当前部署状态。

## 2026-11 v9 三专家更新（历史失败实验）

当前代码已加入 0–800 mm/hr 的三专家研究方案：low 0–50、medium 30–300、high 200–800 mm/hr；降雨时长 1–24 小时，模拟时域 36 小时。有限体积损失使用 Audusse 水静力重构与 HLL 通量；v9 以静水平衡分布乘上初始恒等的可学习修正，解冻时不会跳变，并保留独立深度/速度网络、掩膜硬边界、湿干前缘采样、顺序无关重复验证、稳健目标预热、分层情境锚定和专家重叠区审核。

训练状态每 50 步原子保存，能够恢复模型、优化器、最佳权重、动态深度修正状态、历史、NumPy/Torch RNG 及累计时间，并对地形、事件和关键配置做身份检查。低雨早期的归一化使用静水体积加权条件求积，实测 0.5 mm/hr、60 秒工况相对全域误差约 0.0000667%，正式推理仍以完整 DEM 精确归一化。完整测试在 Python 3.12/Linux CPU 环境为 **167 项执行、167 项通过、无跳过**。

v9 low 专家已完成 6000 步并按严格门槛判定失败：测试平均 continuity loss 为 28451.57，最坏全事件为 154481.65；动量、硬边界和全域水量约束则保持稳定。诊断确认全时段瞬时静水先验与均匀降雨的局部连续方程冲突。当前增加了可重复的 v10 low 800 步消融入口 `probe_minxiong_low.py`，并把深度/速度网络改为可独立裁剪和记录梯度；消融结果仍须通过后才能改动正式三专家配置。

这些是实现与自动测试证据，不是 v9 已训练成功的声明。只有三个专家物理门槛及 30–50、200–300 mm/hr 重叠区一致性全部通过，审核器才会生成批准 manifest；在此之前 GUI 继续回退到 v4 0.5–23 mm/hr 模型。

## VS Code固定地形工作流更新

民雄日常预测现可在 VS Code 安装推荐 Python/Debugger 扩展、选择项目解释器，按 F5 启动 **民雄 PINN：用户输入预测**。雨强、降雨时长、模拟时长和输出间隔直接在图形窗口输入，不需要编辑 JSON。固定地形始终读取 `data/minxiong/裁剪后民雄.tif`；NoData 由 raster mask 判定，高程正负不参与有效性判断。原 `configs/vscode_run.json`/`run_in_vscode.py` 仍是 synthetic 开发演示。

每次生成自包含中文`training_results_report.html`和Markdown：训练状态、Loss/梯度、PDE/IC/BC、参考误差（若有）、水量、内嵌图表、异常和固定地形指纹。只预测时显示所加载模型的历史训练记录，不伪造本次训练。默认仍为固定合成地形短跑，未完成民雄真实验收。

新增桌面入口/报告/平台兼容性回归；包括连续两次改变人为雨强但地形字节和指纹不变、仅推理不训练、错误和不可用输出路径保留失败报告、报告HTML转义/缺测/内嵌图、中文UTF-8/BOM输入、Windows不依赖resource等。当前全套 167 项测试全部执行并通过，无跳过。平台实际运行证据为Linux，未宣称原生Windows实机测试。民雄完整使用步骤见`MINXIONG_VSCODE_GUIDE.md`。

## 端到端短跑与明确的失败结论

可查看当前实例的`outputs/final_demo/training/`、`prediction/`和`assessment.json`。这是30格、6秒物理时域、16宽2层的人工平地示例，非民雄地形；100次Adam加最多5次LBFGS内部迭代，优化预算60秒。参考是平地封闭均匀雨解析式，并非真实淹水观测。

完整流程生成了history/report/PDE/参考指标、模型包、5帧CSV、71个唯一面的交换表、逐格/全域账本、摘要/元数据、manifest和图表。终端返回training_completed/complete只表示任务执行结束，不等于converged或validated。

该短训模型**未通过示例误差/水量门槛**：独立测试雨情的深度和连续残差仍较大，初始人工水量与全域余差也明显。评估命令保存失败项并返回退出码2；不放宽阈值、不清除失败、不将短训权重加入validated_domain。所有研究推理输出明确`research_unvalidated`。

本实例最终短跑优化约2.88秒，加载约0.006秒、完整5帧推理/求积/导出及绘图约1.67秒，进程峰值RSS约281MiB。留出测试水深相对L2约41.1%，最大时刻全域水量余差约0.525m³，因此不能作为可信预测。小型合成性能不能外推全乡或GPU。机器可读结果见`verification_results.json`；原始CSV/JSON位于上述outputs目录。

示例门槛在`configs/synthetic_standards.json`，仅用于演示可解释检查，不是团队已批准的民雄业务标准。`assess`比较指定指标，不自动认证外部准确性或修改模型有效域。
